# 3.1 线性回归：从数学基础到 PyTorch 训练

> 本节对应 3.1 线性回归 文件夹中的 Notebook，重点整理线性回归的基本概念、数学表达、数据构造、损失函数、梯度下降、小批量训练，以及 PyTorch 的两种实现方式。

线性回归是深度学习训练中最基础的模型之一。它的结构非常简单，但训练过程已经包含了神经网络训练的完整骨架：

~~~text
准备数据 → 定义模型 → 计算预测值 → 计算损失 → 反向传播 → 更新参数 → 重复训练
~~~

后面的多层感知机、卷积神经网络等模型，训练流程基本都可以归结为这条主线。

---

## 一、什么是回归问题

回归的目标是根据一个或多个输入变量，预测一个连续数值。

例如：

- 根据房屋面积、房间数量预测房价；
- 根据历史销量预测未来销量；
- 根据病人的特征预测住院天数；
- 根据温度、湿度等因素预测用电量。

回归问题的标签通常是实数，例如 23.5、100000 或 6.66。这与分类问题不同：分类的输出通常是有限个类别，例如猫、狗，或者正面、负面。

### 1. 回归与分类的区别

| 对比项 | 回归 | 分类 |
| --- | --- | --- |
| 预测目标 | 连续数值 | 离散类别 |
| 示例 | 预测房价 | 判断图片是猫还是狗 |
| 常见输出 | 12.7 | 类别 0、类别 1 |
| 常见损失 | MSE、RMSE、MAE | 交叉熵 |
| 常见评价指标 | MSE、RMSE、MAE | 准确率、精确率、召回率 |

需要注意，“预测”不一定就是回归。预测明天是否下雨是分类问题；预测明天的降雨量是多少才是回归问题。

## 二、线性回归模型

### 1. 单个特征

当输入只有一个特征时，线性回归模型为：

$$
\hat{y}=wx+b
$$

其中：

- x：输入特征；
- w：权重，也叫参数；
- b：偏置，也叫截距；
- ŷ：模型给出的预测值。

这里的 ŷ 读作“y_hat”，表示预测值；真实标签通常写作 y。

### 2. 多个特征

当输入有 d 个特征时：

$$
\hat{y}=w_1x_1+w_2x_2+\cdots+w_dx_d+b
$$

用向量内积表示就是：

$$
\hat{y}=\langle \mathbf{w},\mathbf{x}\rangle+b
$$

如果有 n 个样本，把所有输入排列成矩阵 X，则可以一次计算所有样本：

$$
\hat{\mathbf{y}}=X\mathbf{w}+b
$$

本节 Notebook 中有两个特征，因此模型是：

$$
\hat{y}=w_1x_1+w_2x_2+b
$$

### 3. 权重和偏置的直观含义

以本节 Notebook 中的例子为例：

$$
y=2x_1-3.4x_2+6.66+\epsilon
$$

这里：

- x1 每增加 1，预测值大约增加 2；
- x2 每增加 1，预测值大约减少 3.4；
- 当所有特征为 0 时，预测值大约为 6.66；
- ε 是随机噪声，用来模拟真实数据中的误差。

权重描述特征对预测值的影响方向和大小：

- w > 0：特征增大，预测值倾向于增大；
- w < 0：特征增大，预测值倾向于减小；
- |w| 越大：在相同尺度下，特征的影响通常越明显。

不过，如果不同特征的量纲差异很大，不能只根据权重绝对值直接比较重要性。实际机器学习中常常需要先对特征进行标准化。

## 三、损失函数：如何衡量预测好坏

模型参数一开始是随机的，因此预测结果通常不准确。我们需要用一个数值衡量预测值和真实值之间的差距，这个数值就是损失（loss）。

### 1. 单个样本的平方损失

线性回归常用平方损失：

$$
\ell(y,\hat{y})=\frac{1}{2}(\hat{y}-y)^2
$$

其中：

- y 是真实值；
- ŷ 是预测值；
- ŷ-y 是预测误差；
- 平方可以消除正负号，并放大较大的错误；
- 前面的 1/2 是为了求导时抵消平方产生的 2，不影响最优参数的位置。

例如真实值为 10：

~~~text
预测值 9  → 误差 -1 → 平方损失 0.5
预测值 7  → 误差 -3 → 平方损失 4.5
~~~

预测偏差 3 的损失是预测偏差 1 的 9 倍，因此平方损失会更重视较大的错误。

### 2. 一个小批量的损失

对于一个批量中的 B 个样本，通常先分别计算每个样本的损失，再求平均：

$$
L=\frac{1}{B}\sum_{i=1}^{B}\frac{1}{2}(\hat{y}_i-y_i)^2
$$

Notebook 中的 squared_loss 返回的是每个样本的损失，而不是直接求平均：

~~~python
def squared_loss(y_hat, y_gt):
    return (1 / 2) * ((y_hat - y_gt.reshape(y_hat.shape)) ** 2)
~~~

因此，如果返回结果形状为 (B, 1)，可以使用：

~~~python
l.sum().backward()
~~~

让反向传播从一个标量开始。训练日志中再用 l.mean() 作为平均损失进行展示。

### 3. 平方损失的梯度

对预测值求导：

$$
\frac{\partial \ell}{\partial \hat{y}}=\hat{y}-y
$$

预测值高于真实值时，梯度为正；预测值低于真实值时，梯度为负。模型会根据这个方向调整参数。

## 四、Notebook 中的人造数据集

为了验证模型能否学到正确参数，Notebook 没有直接使用复杂真实数据，而是先按照已知公式制造数据。

### 1. 数据生成函数

~~~python
def synthetic_data(w, b, n):
    x = torch.normal(0, 1, (n, len(w)))
    y = torch.matmul(x, w) + b
    y += torch.normal(0, 0.015, y.shape)
    return x, y.reshape(-1, 1)
~~~

逐行理解：

~~~python
def synthetic_data(w, b, n):
~~~

定义一个生成合成数据的函数。参数 w 和 b 是事先设定的真实参数，n 是样本数量。

~~~python
x = torch.normal(0, 1, (n, len(w)))
~~~

从均值为 0、标准差为 1 的正态分布中生成输入特征。如果 w 有两个元素、n=1000，那么 x.shape=(1000, 2)，表示 1000 个样本、每个样本有 2 个特征。

~~~python
y = torch.matmul(x, w) + b
~~~

执行矩阵乘法，按照规律 y=2x1-3.4x2+b 生成标签。torch.matmul(x, w) 对应矩阵形式的 Xw。

~~~python
y += torch.normal(0, 0.015, y.shape)
~~~

生成与 y 形状相同的随机噪声并加到标签上。没有噪声时，数据完全由确定公式产生；加噪声后更接近真实世界。

~~~python
return x, y.reshape(-1, 1)
~~~

返回输入和标签。reshape(-1, 1) 把标签整理成二维列向量：(n,) → (n, 1)；-1 表示由 PyTorch 自动计算这一维的大小。

### 2. 设定真实参数并生成数据

~~~python
w_gt = torch.tensor([2, -3.4])
b_gt = torch.tensor([6.66])
features, labels = synthetic_data(w_gt, b_gt, 200000)
~~~

gt 是 ground truth 的缩写，表示真实值。数据真正遵循的规律是：

$$
y=2x_1-3.4x_2+6.66+\epsilon
$$

训练时模型并不知道 w_gt 和 b_gt，它只能从 features 和 labels 中逐渐学习出接近它们的参数。

### 3. 检查一条样本

~~~python
print(f'feature: {features[0]},\n labels: {labels[0]}')
~~~

features[0] 取第一个样本的全部特征，labels[0] 取对应标签。比如特征为 [-2.4302, -0.3121] 时：

$$
2\times(-2.4302)-3.4\times(-0.3121)+6.66\approx2.864
$$

再考虑随机噪声，就会接近 Notebook 打印出来的标签。

## 六、小批量读取数据

### 1. 为什么使用小批量

如果每次更新参数都使用完整训练集，数据量很大时会耗时较长，而且参数更新频率较低。因此深度学习通常把训练集划分为许多小批量（mini-batch），每次只使用一小部分样本近似计算梯度。

### 2. Notebook 中的生成器

~~~python
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]
~~~

逐行说明：

~~~python
num_examples = len(features)
~~~

获取样本数量。对于形状 (n, d) 的特征矩阵，len(features) 返回第一维 n。

~~~python
indices = list(range(num_examples))
random.shuffle(indices)
~~~

生成所有样本下标并随机打乱，避免模型总是按照相同顺序看到训练样本。

~~~python
for i in range(0, num_examples, batch_size):
~~~

以 batch_size 为步长遍历所有样本。最后一个批次可以少于 batch_size。

~~~python
batch_indices = torch.tensor(
    indices[i: min(i + batch_size, num_examples)])
~~~

取出当前批次的下标。min 防止最后一次切片超出范围。

~~~python
yield features[batch_indices], labels[batch_indices]
~~~

yield 说明这是生成器函数。调用后不会一次返回所有批次，而是每次循环产生一个批次，从而节省内存。

使用方式：

~~~python
batch_size = 10
for X, y in data_iter(batch_size, features, labels):
    print(X.shape, y.shape)
    break
~~~

如果每个样本有 2 个特征，则输出形状为 X.shape=(10, 2)、y.shape=(10, 1)。

### 3. 小批量梯度下降

完整数据集的梯度为：

$$
g=\frac{1}{n}\sum_{i=1}^{n}\nabla \ell_i
$$

小批量梯度使用批量中的 B 个样本近似：

$$
\tilde{g}=\frac{1}{B}\sum_{i\in\text{batch}}\nabla \ell_i
$$

当批量大小不是 1，也不是整个数据集时，这种方法通常称为小批量随机梯度下降（mini-batch SGD）。

## 七、从零实现线性回归

### 1. 定义模型

~~~python
def linreg(X, w, b):
    return torch.matmul(X, w) + b
~~~

如果 X.shape=(B, 2)、w.shape=(2, 1)、b.shape=(1,)，则矩阵乘法结果和最终预测值的形状都是 (B, 1)。加上 b 时，PyTorch 会通过广播把同一个偏置应用到每个样本。

### 2. 定义平方损失

~~~python
def squared_loss(y_hat, y_gt):
    return (1 / 2) * ((y_hat - y_gt.reshape(y_hat.shape)) ** 2)
~~~

y_gt.reshape(y_hat.shape) 把真实标签调整成与预测值完全相同的形状，避免形状不同导致错误广播。

例如 y_hat.shape=(50, 1)、y_gt.shape=(50,) 时，直接相减可能产生 (50, 50) 的结果；先 reshape 后才能逐个样本相减。

### 3. 初始化参数

~~~python
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
~~~

权重从均值为 0、标准差为 0.01 的正态分布中随机初始化，偏置初始化为 0。requires_grad=True 表示需要记录与参数有关的运算，以便之后求导。

### 4. 手写 SGD 优化器

~~~python
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()
~~~

with torch.no_grad() 表示参数更新不属于模型前向计算，不要把更新操作记录进新的计算图。

param -= lr * param.grad / batch_size 是梯度下降公式：

$$
\theta\leftarrow\theta-\eta\frac{1}{B}\nabla_\theta\sum_{i=1}^{B}\ell_i
$$

梯度指向损失增大的方向，所以要减去梯度，朝损失减小的方向移动。

param.grad.zero_() 用来清空梯度。PyTorch 默认会累加梯度，如果不清零，下一批数据的梯度会叠加到上一批梯度上。

### 5. 一次更新的完整过程

~~~python
y_hat = linreg(X, w, b)
l = squared_loss(y_hat, y)
l.sum().backward()
sgd([w, b], lr, batch_size)
~~~

这几行对应完整训练步骤：

~~~text
前向计算 → 计算损失 → 反向传播 → 更新参数并清空梯度
~~~

l.sum().backward() 中的 sum 把每个样本的损失合成一个标量，因为无参数的 backward() 通常要求输出是标量。

## 八、训练循环

下面是一段整理后的完整从零训练代码：

~~~python
import random
import torch


def synthetic_data(w, b, n):
    X = torch.normal(0, 1, (n, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.015, y.shape)
    return X, y.reshape(-1, 1)


def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i:min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]


def linreg(X, w, b):
    return torch.matmul(X, w) + b


def squared_loss(y_hat, y):
    y = y.reshape(y_hat.shape)
    return (y_hat - y) ** 2 / 2


def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()


true_w = torch.tensor([2.0, -3.4])
true_b = torch.tensor([6.66])
features, labels = synthetic_data(true_w, true_b, 2000)

w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

lr = 0.03
num_epochs = 10
batch_size = 50

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = squared_loss(linreg(X, w, b), y)
        l.sum().backward()
        sgd([w, b], lr, batch_size)

    with torch.no_grad():
        train_l = squared_loss(linreg(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {train_l.mean():f}')

print('learned w:', w)
print('true w:', true_w)
print('learned b:', b)
print('true b:', true_b)
~~~

### 1. 为什么要有 epoch

一个 epoch 表示完整遍历一次训练集。

如果有 2000 个样本、批量大小为 50：

$$
\text{每个 epoch 的批次数}=\frac{2000}{50}=40
$$

当 num_epochs=10 时，总共会进行约 400 次小批量参数更新。

### 2. 为什么训练损失会下降

初始参数接近随机值，预测通常很差，损失较大。每个批次都会根据梯度对参数做一次修正。如果学习率合适，参数会逐渐接近真实值，损失也会下降。

由于标签中加入了随机噪声，模型通常不会把损失降到严格的 0；它只能学习数据中的主要线性规律。

### 3. 最终参数应该接近什么

本例真实参数是：

~~~text
w_gt = [2, -3.4]
b_gt = 6.66
~~~

训练结束后，学习到的参数应大致接近：

~~~text
w ≈ [2, -3.4]
b ≈ 6.66
~~~

每次生成的数据都有随机性，因此最后的小数位不会完全相同。

## 九、梯度是怎样传回参数的

对单个样本：

$$
\hat{y}=\mathbf{x}^T\mathbf{w}+b
$$

平方损失：

$$
\ell=\frac{1}{2}(\hat{y}-y)^2
$$

根据链式法则：

$$
\frac{\partial \ell}{\partial \hat{y}}=\hat{y}-y
$$

又因为：

$$
\frac{\partial \hat{y}}{\partial \mathbf{w}}=\mathbf{x},
\qquad
\frac{\partial \hat{y}}{\partial b}=1
$$

所以：

$$
\frac{\partial \ell}{\partial \mathbf{w}}=(\hat{y}-y)\mathbf{x}
$$

$$
\frac{\partial \ell}{\partial b}=\hat{y}-y
$$

这解释了为什么：

- 误差越大，参数更新通常越明显；
- 某个特征的数值越大，它对对应权重梯度的影响越大；
- 偏置梯度等于预测误差的累积。

PyTorch 会自动完成这些求导工作。只要参数设置了 requires_grad=True，并且从参数出发的运算被记录在计算图中，调用 backward() 后就可以读取：

~~~python
print(w.grad)
print(b.grad)
~~~

## 十、PyTorch 的简洁实现

从零实现有助于理解原理，但实际项目通常使用 PyTorch 已经提供的模块和优化器。

### 1. 使用 nn.Linear

~~~python
from torch import nn

net = nn.Sequential(nn.Linear(2, 1))
~~~

nn.Linear(2, 1) 表示一个线性层：

- 输入特征数为 2；
- 输出特征数为 1；
- 内部自动创建权重和偏置。

它完成的计算就是：

$$
\hat{y}=XW+b
$$

### 2. 初始化参数

~~~python
net[0].weight.data.normal_(0, 0.01)
net[0].bias.data.fill_(0)
~~~

- net[0] 取出顺序容器中的第一个线性层；
- weight.data.normal_(0, 0.01) 用正态分布初始化权重；
- bias.data.fill_(0) 把偏置初始化为 0。

现代 PyTorch 代码中更推荐使用初始化工具或在 torch.no_grad() 中操作参数，但这里的写法适合展示 Notebook 的基础内容。

### 3. 使用均方误差损失

~~~python
loss = nn.MSELoss()
~~~

MSELoss 是均方误差损失。默认会对批次中的损失求平均，因此相当于：

$$
L=\frac{1}{B}\sum_{i=1}^{B}(\hat{y}_i-y_i)^2
$$

它与从零实现的平方损失只差一个常数因子 1/2，不改变最优参数，只会影响梯度的具体数值和学习率的匹配。

### 4. 使用 SGD 优化器

~~~python
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
~~~

这里创建随机梯度下降优化器：

- net.parameters()：把网络中的权重和偏置交给优化器；
- lr=0.03：设置学习率。

优化器会自动完成从零实现中的参数更新和梯度清零工作。

### 5. 简洁训练循环

~~~python
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)
        trainer.zero_grad()
        l.backward()
        trainer.step()

    l = loss(net(features), labels)
    print(f'epoch {epoch + 1}, loss {l:f}')
~~~

逐行说明：

~~~python
l = loss(net(X), y)
~~~

先调用 net(X) 得到预测值，再计算当前批次的损失。

~~~python
trainer.zero_grad()
~~~

清空上一批数据留下的梯度。PyTorch 的梯度默认累加，所以这是每个批次中不可缺少的一步。

~~~python
l.backward()
~~~

自动计算损失对网络参数的梯度。

~~~python
trainer.step()
~~~

使用刚刚计算出的梯度更新参数。

这三行就是 PyTorch 训练循环中最核心的固定模式：

~~~python
trainer.zero_grad()
l.backward()
trainer.step()
~~~

## 十一、从零实现与简洁实现的对应关系

| 训练步骤 | 从零实现 | PyTorch 简洁实现 |
| --- | --- | --- |
| 定义模型 | linreg(X, w, b) | nn.Linear(2, 1) |
| 定义损失 | squared_loss | nn.MSELoss() |
| 管理参数 | 手动创建 w、b | 线性层自动创建 |
| 计算梯度 | l.sum().backward() | l.backward() |
| 更新参数 | 自定义 sgd | trainer.step() |
| 清空梯度 | param.grad.zero_() | trainer.zero_grad() |
| 数据迭代 | 自定义 data_iter | DataLoader |

两种实现的数学目标相同。区别在于：

- 从零实现暴露了每个细节，适合理解训练原理；
- 简洁实现使用框架封装，适合编写实际项目。

## 十二、关键超参数

### 1. 学习率 lr

学习率控制每次参数更新的步长。

- 太小：训练很慢，可能在有限时间内还没有学好；
- 太大：损失可能震荡甚至发散；
- 合适：损失整体下降，参数逐渐稳定。

学习率不是越小越好，也不是越大越好，而是需要和数据尺度、模型结构、优化器配合。

### 2. 批量大小 batch_size

批量大小决定每次用多少个样本计算梯度。

- 小批量：更新次数多，梯度噪声较大，但通常更灵活；
- 大批量：梯度更稳定，但占用更多内存，每个 epoch 的更新次数更少。

### 3. 训练轮数 num_epochs

训练轮数决定完整遍历数据集多少次。

- 太少：模型可能还没有收敛；
- 太多：训练时间增加，真实任务中还可能过拟合。

本节是人造线性数据，模型结构正确时通常很快就能学到接近真实参数。

## 十三、现有 Notebook 中需要特别注意的地方

### 1. w 和 b 必须先初始化

训练单元格中使用了：

~~~python
l = loss(net(X, w, b), y)
~~~

因此在运行训练循环前，必须已经执行：

~~~python
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
~~~

如果直接从训练单元格开始运行，可能出现 NameError，或者沿用 Notebook 内核中旧的变量状态。阅读 Notebook 时要注意单元格的执行顺序和当前内核状态。

### 2. 注释中的样本数和代码可能不一致

Notebook 中生成数据使用了 200000 个样本，但部分注释以 2000 个样本为例；训练轮数的注释也可能与当前代码不完全一致。理解时以实际代码中的变量值为准。

### 3. b 的形状

下面两种写法通常都能参与广播：

~~~python
b = torch.tensor([6.66])   # 形状 (1,)
b = torch.tensor([[6.66]]) # 形状 (1, 1)
~~~

为了让线性层输出清晰，建议统一使用 (1,) 或与输出保持一致的形状，并在计算过程中检查：

~~~python
print(X.shape, w.shape, b.shape, y_hat.shape)
~~~

### 4. l.sum().backward() 与 l.mean().backward()

如果 l 是每个样本一个损失的张量，就不能直接对非标量张量调用无参数的 backward()。可以：

~~~python
l.sum().backward()
~~~

也可以：

~~~python
l.mean().backward()
~~~

但两者的梯度会相差一个批量大小的比例，因此学习率的解释也会不同。使用自定义 SGD 时，如果先 sum 再除以 batch_size，就等价于使用批量平均梯度。

### 5. torch.no_grad() 只用于不需要求导的区域

参数更新时使用：

~~~python
with torch.no_grad():
    w -= ...
~~~

训练结束后计算日志时也可以使用 no_grad，因为记录损失不需要再建立反向传播计算图。

不要把正常的前向计算和损失计算全部放进 no_grad，否则模型无法反向传播。

### 6. autograd 会记录运算，但梯度不会自动清空

requires_grad=True 只表示需要记录计算并计算梯度，不表示每次计算前会自动清空梯度。清零必须由用户或优化器显式完成。

## 十四、常见错误排查

### 错误 1：矩阵维度不匹配

报错通常与 mat1 and mat2 shapes cannot be multiplied 有关。

检查：

~~~text
X.shape = (batch_size, 特征数)
w.shape = (特征数, 1)
~~~

如果输入有 2 个特征，权重的第一维必须是 2。

### 错误 2：标签形状导致错误广播

推荐统一标签形状：

~~~python
y = y.reshape(-1, 1)
~~~

并确保：

~~~python
y_hat.shape == y.shape
~~~

### 错误 3：忘记清零梯度

症状是损失下降异常、参数更新越来越大，或者训练结果不稳定。

从零实现中检查：

~~~python
param.grad.zero_()
~~~

简洁实现中检查：

~~~python
trainer.zero_grad()
~~~

### 错误 4：学习率过大

如果损失一开始下降，随后突然变得很大，或者在几个数值之间剧烈震荡，优先尝试减小学习率，例如从 0.03 改为 0.01 或 0.003。

### 错误 5：没有执行参数初始化单元格

Notebook 允许单独运行任意单元格，但变量依赖仍然存在。建议从上到下运行全部单元格，或按照以下顺序运行：

~~~text
导入库 → 定义函数 → 定义真实参数 → 生成数据 → 初始化模型参数 → 训练 → 查看结果
~~~

## 十五、本节知识总结

### 必须掌握的概念

- 回归用于预测连续数值；
- 线性回归模型为 ŷ = Xw + b；
- w 是权重，b 是偏置；
- 平方损失用于衡量预测误差；
- 梯度指向损失增大的方向；
- 梯度下降要沿梯度反方向更新参数；
- 小批量梯度用部分样本近似整体梯度；
- 一个 epoch 表示完整遍历一次训练集。

### 必须掌握的代码模式

从零实现：

~~~python
l = loss(net(X, w, b), y)
l.sum().backward()
sgd([w, b], lr, batch_size)
~~~

PyTorch 简洁实现：

~~~python
l = loss(net(X), y)
trainer.zero_grad()
l.backward()
trainer.step()
~~~

### 最核心的一句话

模型训练不是“直接得到正确答案”，而是不断重复下面的过程：

~~~text
用当前参数预测 → 计算预测有多错 → 求出错误对参数的影响 → 修改参数
~~~

## 十六、建议练习

6. 在训练过程中每个 epoch 打印 w 和 b，观察参数如何逐渐接近真实值。
7. 使用 nn.Linear 的简洁实现替换手写 linreg，比较两种代码的对应关系。
8. 将特征数从 2 改为 3，重新修改真实权重、数据生成函数和线性层输入维度。
