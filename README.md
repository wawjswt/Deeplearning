# Deeplearning

一个用于整理深度学习学习笔记、基础代码和小项目实验的仓库。

## 内容概览

- `2.1数据操作`、`2.2数据预处理`、`2.3线性代数`、`2.4矩阵计算`：深度学习基础知识笔记
- `convolution`：卷积相关内容
- `EmotionClassification`：情感分类相关实验
- `TransferingLearning`：迁移学习相关实验
- `picturestyle`：风格迁移相关内容
- `data`、`dataset`：数据与样例资源
- `BasicFunc.py`、`autograd.py`、`read_data.py`、`main.py`：常用示例脚本

## 运行环境

- Python 3.x
- 建议使用 `PyTorch`、`NumPy`、`Jupyter Notebook` 等深度学习常用库

## 使用方式

1. 克隆或打开仓库
2. 根据需要进入对应目录查看笔记或代码
3. 运行 `.py` 脚本，或使用 `jupyter notebook` 打开 `.ipynb` 文件

## 目录说明

- 笔记类内容以章节目录组织
- 代码示例按主题拆分在独立文件或目录中
- 数据集文件统一放在 `data` 或 `dataset`

## 说明

本仓库主要用于学习和实验，内容会随着整理持续补充。
