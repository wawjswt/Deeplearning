## 参考答案

### 基础答案

1. 张量是多维数组。标量是 0 维，向量是 1 维，矩阵是 2 维，三维张量就是 3 维数组。
2. `shape` 表示每个维度的长度，维度表示张量有几层索引结构。
3. 因为张量便于统一表示图像、文本、数值特征等数据。
4. 按元素运算是两个张量对应位置逐个计算。
5. 广播机制是不同形状张量做运算时自动扩展较小维度。

6. 代码：
```python
import torch

a = torch.zeros(2, 3)
b = torch.ones(3, 3)
c = torch.arange(12)
d = c.reshape(3, 4)
e = torch.rand(2, 2)
print(a, b, c, d, e.shape)
```

7. 索引参考：
```python
x = torch.arange(12).reshape(3, 4)
row2 = x[1]
col3 = x[:, 2]
sub = x[:2, :2]
x[0, 1] = 99
x[:2, :] = 9
```

### 进阶答案

1. `x.reshape(6, 4)`。
2. `x.T` 或 `x.t()`（二维张量时）。
3. 可用 `unsqueeze` 增加维度，再用 `squeeze` 去掉维度。
4. `reshape` 更灵活，可能返回新视图或新张量；`view` 通常要求内存连续。
5. 会报错，因为元素个数不一致。

6. 广播答案：
   - 标量可直接广播
   - `1 x 4` 可沿第 0 维扩展
   - `3 x 1` 可沿第 1 维扩展
   - `2 x 3` 和 `3 x 2` 不能广播
   - 规则：从后往前对齐，每一维要么相等，要么其中一个是 `1`

7. 代码示例：
```python
import torch

x = torch.arange(20).reshape(4, 5)
even_pos = x[::2, ::2]

y = torch.eye(3)

z = torch.arange(16).reshape(4, 4)
z[:, -1] += 10

base = torch.zeros(3, 4)
offset = torch.tensor([[1], [2], [3]])
result = base + offset

print(even_pos)
print(y)
print(z)
print(result)
```

### 挑战答案

1. 可以先取 `x[1:4, 1:4]`。
2. 用列向量广播，例如 `x * torch.tensor([[1, 2, 3, 4]])`。
3. `x[1]` 取出第二个平面，再修改其中元素。
4. 先切片再 reshape，例如 `x[:8].reshape(3, 2)`。
5. 示例：
```python
import torch

x = torch.arange(24).reshape(2, 3, 4)
part = x[1]
part[0, 0] = 100
flat = x.reshape(-1)
slice_part = flat[:12]
final = slice_part.reshape(3, 4)
add = final + torch.tensor([[1], [2], [3]])
print(add.shape)
```

6. 思考题参考：
   - 视图可以节省内存
   - 广播减少重复写代码
   - shape 错误常见于拼接、矩阵乘法、输入层
   - 检查维度能减少隐藏 bug
   - 例如图像分类、文本分类、回归任务都依赖正确的数据形状
