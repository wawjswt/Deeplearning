# 2.5 自动求导：知识点总结与训练题

> 本文根据本节 Notebook 中的 PyTorch 自动求导示例整理，包括计算图、梯度存储、反向传播、梯度累加、非标量输出、`detach()` 和动态控制流等内容。

## 一、知识点总结

### 1. 自动求导的作用

自动求导（Automatic Differentiation）用于计算函数在指定输入值处的导数或梯度。深度学习训练时，通常利用自动求导计算损失函数对模型参数的梯度，再根据梯度更新参数。

PyTorch 的 `torch.autograd` 会记录张量之间的运算关系，并构建计算图。在调用 `backward()` 时，PyTorch 根据链式法则从输出向输入反向传播梯度。

### 2. 标量、向量与梯度

设标量函数为：

$$
y=f(\mathbf{x}), \quad \mathbf{x}\in\mathbb{R}^n
$$

则 $y$ 对 $\mathbf{x}$ 的梯度为：

$$
\nabla_{\mathbf{x}}y=
\begin{bmatrix}
\frac{\partial y}{\partial x_1} &
\frac{\partial y}{\partial x_2} &
\cdots &
\frac{\partial y}{\partial x_n}
\end{bmatrix}
$$

在数学表达中，标量对列向量求导常写成行向量；在 PyTorch 中，梯度张量通常与被求导张量具有相同的形状。

### 3. 开启梯度跟踪

创建张量后，可以通过以下方式让 PyTorch 跟踪它参与的运算：

```python
x = torch.arange(4, dtype=torch.float)
x.requires_grad_(True)
```

也可以在创建张量时直接指定：

```python
x = torch.arange(4, dtype=torch.float, requires_grad=True)
```

注意：

- `requires_grad=True` 表示需要计算该张量的梯度。
- 在第一次反向传播之前，`x.grad` 通常为 `None`。
- 对浮点数或复数张量才能启用梯度跟踪，整数张量不能直接计算梯度。

### 4. `backward()` 与梯度存储

示例：

```python
x = torch.arange(4, dtype=torch.float, requires_grad=True)
y = 2 * torch.dot(x, x)
y.backward()
print(x.grad)
```

因为：

$$
y=2\mathbf{x}^T\mathbf{x}=2\sum_i x_i^2
$$

所以：

$$
\frac{\partial y}{\partial \mathbf{x}}=4\mathbf{x}
$$

因此可以验证：

```python
x.grad == 4 * x
```

调用 `y.backward()` 后，叶子张量 `x` 的梯度会保存在 `x.grad` 中。

### 5. 梯度默认会累加

PyTorch 不会在每次调用 `backward()` 前自动清空已有梯度，而是把新梯度累加到 `.grad` 中。

```python
x.grad.zero_()
```

上述代码会将 `x.grad` 原地清零。在每轮训练中，通常需要先清空上一轮的梯度，再进行新的反向传播。

常见训练顺序如下：

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

### 6. 对求和函数求导

若：

```python
y = x.sum()
y.backward()
```

则：

$$
y=x_1+x_2+\cdots+x_n
$$

因此：

$$
\frac{\partial y}{\partial x_i}=1
$$

最终 `x.grad` 是一个与 `x` 同形状的全 1 张量。

### 7. 非标量输出的反向传播

`backward()` 最自然的使用场景是输出为标量，例如深度学习中的损失 `loss`。

如果：

```python
y = x * x
```

那么 `y` 是向量，不能直接把“向量对向量的完整导数”简单地存入 `x.grad`，因为完整结果应是雅可比矩阵。常见处理方式是先将输出求和为标量：

```python
y.sum().backward()
```

此时实际计算的是：

$$
\frac{\partial}{\partial \mathbf{x}}\sum_i y_i
$$

对于 `y = x * x`，结果为：

$$
2\mathbf{x}
$$

也可以向非标量张量的 `backward()` 传入一个与输出同形状的外部梯度，本质上计算向量—雅可比积。

### 8. `detach()`：切断计算图

示例：

```python
y = x * x
u = y.detach()
z = u * x
z.sum().backward()
```

`u` 与 `y` 的数值相同，但 `u` 已经从当前计算图中分离。在后续求导时，`u` 被视为不依赖 `x` 的常量。

由于：

$$
z_i=u_i x_i
$$

并且求导时把 $u_i$ 当作常数，所以：

$$
\frac{\partial}{\partial x_i}\sum_j z_j=u_i
$$

因此有：

```python
x.grad == u
```

如果不使用 `detach()`，而直接令 `z = y * x = x^3`，则 `z.sum()` 对 `x` 的梯度为 `3 * x**2`。

### 9. 动态计算图与控制流

PyTorch 使用动态计算图，因此在前向计算中可以使用 Python 的 `if`、`while` 等控制流。

```python
def f(a):
    b = 2 * a
    while b.norm() < 1000:
        b *= 2
    if b.sum() > 0:
        c = b
    else:
        c = 100 * b
    return c
```

不同输入可能进入不同分支、执行不同次数的循环。PyTorch 会根据本次实际执行的运算构建计算图，然后正确应用链式法则。

在该函数的一次具体运行中，输出 `d` 最终是输入 `a` 的某个常数倍，即：

$$
d=ka
$$

所以：

$$
\frac{\mathrm{d}d}{\mathrm{d}a}=k=\frac{d}{a}
$$

当 `a != 0` 时，可以使用下面的代码验证：

```python
a.grad == d / a
```

### 10. 计算图的释放与重复反向传播

默认情况下，完成一次 `backward()` 后，用于反向传播的中间计算图会被释放。因此，对同一个输出张量连续调用两次 `backward()` 通常会报错。

如果确实需要在同一张图上多次反向传播，可以使用：

```python
y.backward(retain_graph=True)
```

不过在普通训练中，一般会重新执行前向计算得到新的计算图，而不是长期保留旧图。

### 11. 常用操作速查

| 操作 | 作用 |
|---|---|
| `requires_grad=True` | 创建张量时开启梯度跟踪 |
| `x.requires_grad_(True)` | 原地开启梯度跟踪 |
| `y.backward()` | 从标量输出开始反向传播 |
| `x.grad` | 查看累积到叶子张量上的梯度 |
| `x.grad.zero_()` | 将已有梯度清零 |
| `y.sum().backward()` | 把非标量输出求和后再反向传播 |
| `y.detach()` | 返回数值相同、但与当前计算图分离的张量 |
| `retain_graph=True` | 反向传播后暂时保留计算图 |

### 题目 1：自动求导的基本概念

请简述 PyTorch 自动求导的基本工作过程，并说明计算图与链式法则之间的关系。

#### 参考答案

当一个设置了 `requires_grad=True` 的张量参与运算时，PyTorch 会记录相关运算并构建计算图。计算图中的节点可以表示张量或运算，边表示数据依赖关系。调用输出张量的 `backward()` 后，PyTorch 从输出节点向输入节点反向遍历计算图，并利用链式法则逐层计算梯度，最终把叶子张量的梯度累积到其 `.grad` 属性中。

### 题目 2：手工求导

设：

$$
y=3\mathbf{x}^T\mathbf{x}=3\sum_{i=1}^{n}x_i^2
$$

求 $y$ 对 $\mathbf{x}$ 的梯度。

#### 参考答案

对每个分量 $x_i$：

$$
\frac{\partial y}{\partial x_i}=6x_i
$$

因此：

$$
\nabla_{\mathbf{x}}y=6\mathbf{x}
$$

对应 PyTorch 验证代码：

```python
import torch

x = torch.arange(4, dtype=torch.float, requires_grad=True)
y = 3 * torch.dot(x, x)
y.backward()
print(x.grad)
print(torch.allclose(x.grad, 6 * x))
```

### 题目 4：梯度为什么要清零

阅读下面的代码：

```python
x = torch.tensor([1.0, 2.0], requires_grad=True)

y1 = (x * x).sum()
y1.backward()

y2 = x.sum()
y2.backward()

print(x.grad)
```

请写出最终结果，并解释原因。

#### 参考答案

第一次反向传播：

$$
\frac{\partial}{\partial \mathbf{x}}\sum_i x_i^2=2\mathbf{x}=[2,4]
$$

第二次反向传播：

$$
\frac{\partial}{\partial \mathbf{x}}\sum_i x_i=[1,1]
$$

因为 PyTorch 默认累加梯度，所以最终：

$$
[2,4]+[1,1]=[3,5]
$$

输出为：

```text
tensor([3., 5.])
```

若只希望保留第二次计算的梯度，应在第二次反向传播前调用：

```python
x.grad.zero_()
```

### 题目 6：非标量输出

下面的代码为什么需要调用 `sum()`？调用后 `x.grad` 是多少？

```python
x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
y = x * x
y.sum().backward()
```

#### 参考答案

`y` 是一个向量。向量对向量的完整导数是雅可比矩阵，而 `.grad` 需要保存与 `x` 同形状的梯度结果。将 `y` 求和后得到标量：

$$
L=x_1^2+x_2^2+x_3^2
$$

于是：

$$
\nabla_{\mathbf{x}}L=2\mathbf{x}=[2,4,6]
$$

所以：

```text
tensor([2., 4., 6.])
```

### 题目 8：理解 `detach()`

阅读代码并写出 `x.grad`：

```python
x = torch.tensor([2.0, 3.0], requires_grad=True)
y = x * x
u = y.detach()
z = u * x
z.sum().backward()
print(x.grad)
```

#### 参考答案

`u` 的数值是：

```text
tensor([4., 9.])
```

但 `detach()` 切断了 `u` 与 `x` 的梯度关系，所以反向传播时 `u` 被当作常量。因为：

$$
z_1+z_2=u_1x_1+u_2x_2
$$

所以对 `x` 的梯度就是 `u`：

```text
tensor([4., 9.])
```

### 题目 9：比较使用与不使用 `detach()`

分别计算下面两段代码中的梯度。

代码 A：

```python
x = torch.tensor([2.0, 3.0], requires_grad=True)
y = x * x
z = y.detach() * x
z.sum().backward()
```

代码 B：

```python
x = torch.tensor([2.0, 3.0], requires_grad=True)
y = x * x
z = y * x
z.sum().backward()
```

#### 参考答案

代码 A 中，`y.detach()` 被视为常量，因此梯度为：

$$
x^2=[4,9]
$$

即：

```text
tensor([4., 9.])
```

代码 B 中：

$$
z=x^2\cdot x=x^3
$$

所以：

$$
\frac{\mathrm{d}z}{\mathrm{d}x}=3x^2
$$

即：

```text
tensor([12., 27.])
```

### 题目 10：链式法则

设：

$$
y=2x, \qquad z=y^3
$$

求 $z$ 对 $x$ 的导数，并写出 PyTorch 验证代码。

#### 参考答案

根据链式法则：

$$
\frac{\mathrm{d}z}{\mathrm{d}x}
=
\frac{\mathrm{d}z}{\mathrm{d}y}
\frac{\mathrm{d}y}{\mathrm{d}x}
=3y^2\cdot2
$$

代入 $y=2x$：

$$
\frac{\mathrm{d}z}{\mathrm{d}x}=3(2x)^2\cdot2=24x^2
$$

验证代码：

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = 2 * x
z = y ** 3
z.backward()
print(x.grad)  # 24 * 2**2 = 96
```

输出为：

```text
tensor(96.)
```

### 题目 11：动态控制流

为什么下面函数即使包含 `while` 和 `if`，PyTorch 仍然能够计算梯度？

```python
def f(a):
    b = 2 * a
    while b.norm() < 1000:
        b *= 2
    if b.sum() > 0:
        c = b
    else:
        c = 100 * b
    return c
```

#### 参考答案

PyTorch 使用动态计算图。每次调用 `f(a)` 时，程序会根据当前输入实际执行一定次数的循环并选择一个分支。PyTorch只记录本次运行中真正执行过的张量运算，并据此构建计算图。因此，即使不同输入产生不同的执行路径，PyTorch 仍可在本次构建的计算图上使用链式法则完成反向传播。

### 题目 12：叶子张量与梯度

阅读代码：

```python
x = torch.tensor(2.0, requires_grad=True)
y = 3 * x
z = y ** 2
z.backward()
```

默认情况下，`x.grad` 与 `y.grad` 分别是什么？

#### 参考答案

`x` 是由用户直接创建并设置 `requires_grad=True` 的叶子张量，所以其梯度会保存在 `x.grad` 中。

由于：

$$
z=(3x)^2=9x^2
$$

所以：

$$
\frac{\mathrm{d}z}{\mathrm{d}x}=18x
$$

当 $x=2$ 时：

```text
x.grad = tensor(36.)
```

`y` 是中间计算结果，不是叶子张量。默认情况下，PyTorch 不会把中间张量的梯度保存在 `.grad` 中，因此：

```text
y.grad = None
```

如果确实需要查看中间张量的梯度，可以在反向传播前调用：

```python
y.retain_grad()
```

### 题目 13：找出并修正错误

下面的程序试图对同一个计算结果连续进行两次反向传播：

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward()
y.backward()
```

程序可能出现什么问题？请给出两种修正方式。

#### 参考答案

第一次 `backward()` 后，默认情况下计算图中的中间信息会被释放。第二次对同一个 `y` 调用 `backward()` 时，程序通常会报告“尝试再次通过已释放的计算图进行反向传播”之类的错误。

修正方式一：第一次反向传播时保留计算图。

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward(retain_graph=True)
y.backward()
```

此时梯度会累加，最终 `x.grad` 为 8，而不是 4。

修正方式二：重新进行前向计算，构建一张新的计算图。

```python
x = torch.tensor(2.0, requires_grad=True)

y = x ** 2
y.backward()

x.grad.zero_()
y = x ** 2
y.backward()
```

最终 `x.grad` 为 4。

### 题目 14：综合编程题

使用 PyTorch 自动求导计算下式在 $x=[1,2,3]$ 处的梯度：

$$
L=\sum_{i=1}^{3}(2x_i^3+5x_i)
$$

要求：

1. 写出理论梯度；
2. 写出 PyTorch 代码；
3. 给出最终梯度值。

#### 参考答案

对每个分量：

$$
\frac{\partial L}{\partial x_i}=6x_i^2+5
$$

所以理论梯度为：

$$
\nabla_{\mathbf{x}}L=6\mathbf{x}^2+5
$$

PyTorch 代码：

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
L = (2 * x ** 3 + 5 * x).sum()
L.backward()
print(x.grad)
```

代入 $x=[1,2,3]$：

$$
[6\times1^2+5,\ 6\times2^2+5,\ 6\times3^2+5]
=[11,29,59]
$$

最终输出：

```text
tensor([11., 29., 59.])
```

### 题目 15：综合分析题

阅读以下代码：

```python
x = torch.tensor([1.0, 2.0], requires_grad=True)

y = x ** 2
u = y.detach()
loss1 = (u * x).sum()
loss1.backward()

first_grad = x.grad.clone()
x.grad.zero_()

loss2 = (x ** 3).sum()
loss2.backward()
second_grad = x.grad.clone()
```

请分别写出 `first_grad` 和 `second_grad`，并解释二者不同的原因。

#### 参考答案

对于 `loss1`，`u = y.detach()` 的数值为 `[1, 4]`，但求导时被视为常量：

$$
loss1=1\cdot x_1+4\cdot x_2
$$

因此：

```text
first_grad = tensor([1., 4.])
```

对于 `loss2`：

$$
loss2=x_1^3+x_2^3
$$

梯度为：

$$
[3x_1^2,3x_2^2]=[3,12]
$$

因此：

```text
second_grad = tensor([3., 12.])
```

二者不同的根本原因是 `detach()` 切断了 `u` 对 `x` 的依赖关系，使第一段反向传播不再经过 `y=x^2` 这部分计算图；第二段则保留了 $x^3$ 的全部依赖关系。

## 三、学习建议

1. 手工推导简单函数的梯度，再用 `backward()` 验证。
2. 每次进行新的独立梯度计算前，检查是否需要调用 `x.grad.zero_()`。
3. 遇到非标量输出时，明确自己需要的是雅可比矩阵、输出元素之和的梯度，还是某个向量—雅可比积。
4. 使用 `detach()` 前，应确认是否真的希望阻止梯度经过该张量继续传播。
5. 调试时重点检查 `requires_grad`、`grad_fn`、`is_leaf` 和 `.grad` 等属性。
